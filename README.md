# Pong Game

This is a simple implementation of the classic Pong game using Python and `pygame`.

## Features
- Two-player mode.
- Score tracking.
- Adjustable paddle and ball speeds.

## Requirements
- Python 3.8+
- Pygame 2.3.0+
